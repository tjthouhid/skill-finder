01 — The reply

Three answers, every time.

i.

Which skill

The best fit for your words, up to two more worth a look, and a guided journey when you're starting a whole project.

Best fit: cro-methodology
ii.

How to install it

One command for each skill you don't have yet, made for the tool you're using. Nothing for skills you already have.

npx skills add wondelai/skills -s cro-methodology -g -a claude-code
iii.

What to say

A ready prompt that names the skill and your goal. Fixing something? It starts small. Building from scratch? It asks for the whole design.

Use cro-methodology to find why my checkout page loses customers. Start with the smallest first step.
02 — How it knows

Built on your machine.

The list it searches is made from your own skill folders, plus curated lists that cover skills you don't have yet. Someone else's list never shows up on your machine.

  1. Reads your folders

    Every SKILL.md in ~/.claude/skills, your Claude Code plugins, ~/.codex/skills, and ~/.agents/skills.

  2. Adds curated lists

    Files in data/sources/ add categories, “use when” notes, journeys, and install commands for skills you haven't installed.

  3. Builds one index

    Everything goes into data/skills.json. If the index came from another machine or is over 30 days old, Skill Finder rebuilds it before it answers.

  4. Ranks your words

    Plain keyword matching with a few synonyms. Rare words count more than common ones, so “portfolio” matters more than “design”. It runs offline.

04 — Install

One line, then ask.

Claude Code~/.claude/skills
npx skills add tjthouhid/skill-finder -g -a claude-code
Codex CLI~/.agents/skills
npx skills add tjthouhid/skill-finder -g -a codex

Needs Python 3.9 or later and Node.js for npx. The -g flag installs the skill for your user account, not one project.

Then, just ask.

  1. Restart Claude Code or Codex CLI so it loads the new skill.
  2. Type /skill-finder followed by your need, or ask “which skill should I use to…”.
  3. Run any install line it gives you, then send the “Try this” prompt.
05 — Grow it

Teach it new lists.

Add these skills to skill finder: https://…

Point it at a skill catalogue, a file, or a pasted list. It shows what it found and saves it once you confirm.

Refresh the skill index

Run this after you install or remove skills. Installed skills are picked up on their own.

python3 -I scripts/find.py "need" --tool codex

Get the raw results in a terminal, without an agent.
